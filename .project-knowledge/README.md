# MasterPHP Project Knowledge

This is the project-local knowledge base for the MasterPHP learning workspace.

Store durable PHP and repository lessons here:
- Verified PHP language and runtime behavior.
- Reproducible debugging findings.
- Composer and tooling conventions.
- Project architecture decisions.
- Database and security lessons.
- Common misconceptions and their corrections.
- Environment setup and troubleshooting notes.

Before meaningful work, agents should inspect `index.yaml`, search relevant entries, and read the full source entry. Record status, confidence, PHP version, evidence, applicability, and limitations.

Do not store credentials, local environment secrets, personal data, or unverified statements as facts. Do not promote project knowledge to shared EMW without sanitization and explicit human approval.
