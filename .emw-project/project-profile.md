# MasterPHP Project Profile

## Product purpose
A personal PHP mastery and project portfolio repository. It combines a structured learning curriculum with progressively more complex PHP projects and serves as a real-world pilot for the Engineering Mastery Workflow.

## Owner and learner context
- Developer: repository owner.
- Starting knowledge: developer reports having some PHP basics.
- Exact proficiency: unassessed; baseline diagnostic pending.
- Learning objective: become independently capable in modern PHP language semantics, runtime, web development, data access, security, testing, architecture, and frameworks.

## Technology direction
- Primary language: PHP.
- Default learning target: PHP 8.6 stable as of 20 November 2026.
- Compatibility stance: preserve PHP 8.5 compatibility where practical.
- Dependency management: Composer.
- Database learning: MySQL/MariaDB with PDO first; PostgreSQL may be introduced for comparison later.
- Testing and analysis: introduce PHPUnit and PHPStan (or equivalent) when fundamentals and project structure justify them.
- Framework specialization: Laravel or Symfony only after meaningful core-PHP evidence.

## Repository structure
- `learning/`: roadmap, modules, labs, exercises, notes, assessments, research, EMW pilot.
- `projects/`: progressive practical portfolio.
- `.emw/`: vendored EMW subset pinned in `.emw/UPSTREAM.md`.
- `.emw-project/`: live learning and delivery state.
- `.project-knowledge/`: durable project knowledge.
- `.opencode/`: OpenCode skills and commands.

## Working agreement
- Begin with baseline assessment, not assumptions about beginner level.
- Use conceptual explanations, pseudocode, prediction, and independent attempts.
- Preserve separate delivery and mastery records.
- Use the adaptive EMW collaboration modes.
- Capture durable verified lessons in the project knowledge base.
- Do not claim mastery without evidence.

## Current milestone
Initialize workspace and complete baseline diagnostic. The learning roadmap is subject to adjustment after baseline review.
