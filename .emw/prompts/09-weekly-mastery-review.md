# EMW Prompt 09 — Weekly Mastery Review

Review available project activity and records for the requested period. Do not invent work or infer activity from absence.

Read:
- Project delivery ledger.
- Developer skill ledger and learning log.
- Relevant task briefs and verification reports.
- Recent ADRs and project knowledge additions.
- Git history or issue records only when accessible and relevant.

Report:
1. Wins and delivered work.
2. Concepts practiced, separating independent demonstrations from AI-guided exposure.
3. Evidence-backed M0–M4 changes; explicitly state when evidence is insufficient.
4. Two or three prioritized knowledge gaps.
5. One short independent retrieval, debugging, or implementation exercise; withhold its answer initially.
6. Next week's learning-aware engineering focus.
7. One concrete way to reduce AI assistance on a previously practiced concept.
8. Useful knowledge discoveries captured or awaiting review.

Do not promote mastery from merged or generated code alone. A feature's delivery status and the developer's mastery status remain separate.
