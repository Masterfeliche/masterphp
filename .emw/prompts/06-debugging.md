# EMW Prompt 06 — Debugging

Use for unexpected behavior, failing tests, incidents, regressions, or hard-to-explain output.

1. Retrieve relevant debugging and project knowledge using Prompt 07.
2. Reproduce the problem or clearly state why reproduction is unavailable.
3. Record exact symptoms, inputs, environment, logs, error messages, and expected behavior.
4. Form and rank hypotheses; separate observations from assumptions.
5. Trace the smallest relevant execution path and use tests, logs, debugger, or instrumentation to isolate the cause.
6. For learning-oriented work, ask the human to predict or investigate before revealing the answer; increase assistance when needed.
7. Identify root cause before applying a fix. Avoid speculative patches and unrelated changes.
8. Add a regression test or other repeatable check.
9. Verify the fix and relevant adjacent cases.
10. Capture the root cause, diagnostic path, verified fix, evidence, and limitations with Prompt 08.

Never present a plausible explanation as a confirmed root cause without supporting evidence. Record assistance A0–A4 and separate the human's independent diagnosis from AI-supplied hypotheses.
