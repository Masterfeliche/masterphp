# Project 04 — Build a Mini MVC Framework (Educational)

**Status:** planned; only begin after PHP OOP, Composer, namespaces, HTTP, testing, and dependency injection have adequate evidence.

## Purpose
Build a deliberately small framework to understand how framework features are constructed. This is an educational codebase, not a production framework.

## Components
- PSR-4 autoloading through Composer.
- HTTP request and response objects.
- Router and route parameters.
- Middleware pipeline.
- Controller dispatch.
- Dependency injection container.
- View rendering.
- Error handling.
- Configuration and tests.

## Constraints
- Implement one concept at a time.
- Compare the design with established framework behavior.
- Avoid implementing security-critical features casually.
- Do not deploy this as a production framework.
- Record where the project intentionally differs from established standards.

## Mastery gate
Explain the request lifecycle from entry point to response, add a route and middleware independently, test failure paths, and defend the dependency-injection design.
