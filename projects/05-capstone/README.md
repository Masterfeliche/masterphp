# Project 05 — PHP Capstone

**Status:** not selected.

This project should be chosen after the foundational and intermediate projects. Select a real problem that requires a coherent, maintainable PHP application rather than a tutorial clone.

## Selection criteria
- A clear user problem and real workflow.
- Enough complexity to exercise domain modeling and architecture.
- Database integrity and meaningful authorization requirements.
- Non-trivial testing and security considerations.
- A realistic deployment and operational story.
- Scope appropriate to a solo developer.

## Candidate directions
- Service/repair job management.
- Inventory and sales management.
- Appointment and booking management.
- Small business operations platform.
- API-first application with a web client.

Do not commit to a capstone before completing baseline assessment and reviewing earlier project evidence.

## Required artifacts
- Product brief and acceptance criteria.
- Architecture notes and ADRs.
- Data model and security boundaries.
- Test and verification strategy.
- Delivery ledger and mastery evidence.
- Operational and deployment notes.
- Post-project transfer assessment.
