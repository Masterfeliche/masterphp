# PHP Projects Portfolio

Projects are the applied track of MasterPHP. Build them in order unless the baseline demonstrates that a project's core concepts are already independently understood.

Each project should have a brief, acceptance criteria, architecture notes, tests, a retrospective, and a linked mastery assessment. Do not build every project simultaneously.

## Progressive sequence

| Project | Focus | Concepts exercised | Status |
|---|---|---|---|
| 00 — MySQL Connection Lab | Review the existing connection experiment | PHP execution, extensions, database connectivity, error handling, safe configuration | Existing starter to review |
| 01 — CLI Expense Tracker | First complete PHP application | Functions, arrays, types, files/JSON, OOP, exceptions, tests | Planned |
| 02 — Contact & Inventory Manager | Server-rendered web application | HTTP, forms, validation, sessions, PDO, SQL, security | Planned |
| 03 — REST API | JSON API | Routing, HTTP, request/response, validation, PDO, auth, tests | Planned |
| 04 — Mini MVC Framework | Educational architecture project | Composer, PSR-4, router, controllers, middleware, DI, testing | Planned |
| 05 — Capstone | Developer-selected real-world system | Architecture, security, data integrity, maintainability, deployment | Not selected |
| 06 — Framework Application | Laravel or Symfony application | Framework internals and professional ecosystem | Later |

## Project rules
1. Complete or explicitly waive the prerequisite mastery gate with evidence.
2. Use EMW to plan and select collaboration modes.
3. Keep a project-local delivery record.
4. Identify which PHP skills the project exercises.
5. Keep solution-level AI assistance proportional to demonstrated proficiency.
6. Test actual behavior and record observed results.
7. After completion, solve a new related task independently.
8. Write a retrospective and capture durable project knowledge.

## First project
Begin by reviewing the existing MySQL connection experiment. Do not treat a successful connection as proof of secure database engineering. The next main application project is the CLI Expense Tracker, which teaches core PHP without hiding behavior behind a web framework.
