# Project 03 — PHP REST API

**Status:** planned.

## Product brief
Build a documented JSON API using PHP, a relational database, and a small explicit request/response layer. This project should teach HTTP behavior and application boundaries before introducing a full framework.

## Core requirements
- Define resource-oriented endpoints.
- Parse and validate JSON request bodies.
- Return correct status codes, headers, and error structures.
- Implement pagination, filtering, and resource lookup.
- Use PDO and transactions where data integrity requires them.
- Implement authentication and object-level authorization.
- Provide automated unit and integration tests.
- Document endpoints and failure behavior.

## Milestones
1. HTTP request/response primitives.
2. Routing and method handling.
3. Validation and error mapping.
4. Persistence and transaction boundaries.
5. Authentication and authorization.
6. API tests and documentation.
7. Logging, configuration, and operational readiness.

## Mastery gate
Implement an unfamiliar endpoint independently, explain its request lifecycle, test boundary and unauthorized cases, and debug a failing integration test.
