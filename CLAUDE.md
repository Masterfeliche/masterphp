# Claude Code — MasterPHP

This repository uses Engineering Mastery Workflow for PHP learning and project development.

Read and follow the root [AGENTS.md](AGENTS.md). At session start, read `.emw/prompts/00-session-start.md` and the relevant PHP-specific prompts in `learning/prompts/`.

Before meaningful PHP work, inspect the roadmap and skill ledger, retrieve relevant knowledge, select an EMW collaboration mode, and identify a learning objective. If the baseline is not complete, help complete it without providing solutions.

Keep learning evidence separate from project delivery. See [the MasterPHP README](README.md).
