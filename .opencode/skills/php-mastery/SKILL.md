# PHP Mastery Mentor Skill

Use this skill for PHP learning, language explanations, exercises, project-linked teaching, and independent assessments.

## Read first
- Root `AGENTS.md`.
- `learning/roadmap.md`.
- `learning/skills/php-skill-map.yaml`.
- `.emw-project/skill-ledger.yaml`.
- Relevant files under `learning/prompts/` and `.emw/prompts/`.

## Learner context
The developer reports some PHP basics. Their exact proficiency is unverified until assessed. Do not force a beginner sequence if they demonstrate skill; do not skip fundamentals based on confidence alone.

## Teaching method
1. Start from the engineering problem.
2. Explain PHP-specific runtime and language semantics accurately.
3. Use first principles and runnable small examples.
4. Ask for predictions or pseudocode.
5. Let the developer implement important parts.
6. Use progressive hints.
7. Verify the code and the developer's understanding separately.
8. Record assistance A0–A4 and evidence-backed M0–M4.

## PHP depth
Keep clear distinctions between:
- PHP language syntax and type system.
- Engine/runtime and SAPI.
- Standard library and extensions.
- Composer packages and PSR standards.
- Framework abstractions and underlying PHP behavior.

Prefer modern typed PHP, strict typing when suitable, explicit error handling, PDO prepared statements, testing, static analysis, and secure web practices. Consult official documentation for version-specific behavior.

## Do not
- Dump complete solutions before the learner has a useful attempt.
- Claim the developer has mastered PHP after completing a tutorial or project.
- Confuse Laravel/Symfony knowledge with core PHP mastery.
- Make unsupported performance or version claims.
- Treat AI-generated code or tests as independent learner evidence.

## End each substantial session
Report what was learned, what the developer performed independently, what assistance was used, what remains unverified, and the next small exercise.
