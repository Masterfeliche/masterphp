# PHP Engineering Skill

Use this skill when implementing or reviewing PHP code in MasterPHP projects.

## Before changes
- Follow root `AGENTS.md` and EMW.
- Read the project brief and acceptance criteria.
- Inspect actual PHP version, extensions, Composer setup, existing architecture, and test commands.
- Retrieve relevant project knowledge and official PHP documentation.
- Assess risk and select a collaboration mode.

## Implementation practices
- Prefer strict types and explicit contracts for new code where appropriate.
- Use Composer and PSR-4 autoloading when project structure warrants it.
- Use PDO prepared statements for SQL.
- Keep credentials outside source control.
- Validate input and escape output contextually.
- Use password hashing APIs, secure session configuration, authorization checks, and CSRF protection where relevant.
- Keep domain logic testable and avoid unnecessary framework dependencies.
- Follow current PHP/Fig standards when applicable; verify versions and details.
- Treat learning frameworks as educational, not production-ready.

## Verification
Run the relevant syntax checks, tests, static analysis, and security checks where available. Report exact commands and results. Never claim checks passed if they were not run.

## Learning outcome
Identify PHP concepts encountered and require an appropriate independent explanation, implementation, debugging, or transfer exercise. Do not infer mastery from code generated by the agent.
