# Personal PHP Notes

Write explanations in your own words. Notes should capture mental models and surprising behavior, not copy the PHP manual.

A useful note contains:
- Concept and PHP versions involved.
- A concise explanation in your own words.
- A minimal example you wrote.
- What you initially misunderstood.
- A prediction and observed output.
- When the concept is useful.
- Edge cases and limitations.
- Official manual links.
- A question to revisit later.

Agent-generated explanations can be used as a starting point, but rewrite the explanation yourself and validate technical details.
