# PHP Assessments

Assessments verify skills with observable evidence; reading or copying examples is not enough.

Assessment types:
- Concept explanation.
- Output prediction and execution tracing.
- Independent implementation.
- Debugging a real or seeded defect.
- Code review and security reasoning.
- Transfer to a related unfamiliar task.
- Delayed retrieval after a meaningful interval.

Use the EMW M0–M4 rubric in `.emw/core/mastery-framework.md`. M3 requires independent implementation, explanation, testing, and debugging. M4 additionally requires transfer and explaining trade-offs.

Every result records task, date, PHP version, assistance A0–A4, test observations, limitations, and evidence links.
