# PHP Learning Workspace

This is the learning track of MasterPHP. It should develop real understanding, not merely collect tutorial notes.

## Start sequence
1. Complete `baseline/baseline-assessment.md` without solution-level AI.
2. Record observations in `../.emw-project/developer-profile.md` and `../.emw-project/skill-ledger.yaml`.
3. Use `roadmap.md` to identify the next module based on demonstrated gaps.
4. Read one concept, predict behavior, experiment in a small lab, and explain the result in your own words.
5. Attempt the exercise independently before requesting hints.
6. Apply concepts in a project under `../projects/`.
7. Reassess with a different task, including delayed retrieval and transfer.

## Learning folders
- `baseline/`: starting diagnostic and baseline evidence.
- `modules/`: structured lessons, goals, prerequisites, and mastery gates.
- `labs/`: small experiments that isolate PHP behavior.
- `exercises/`: independent problem-solving tasks.
- `assessments/`: practical assessments and rubrics.
- `notes/`: your own mental models and explanations.
- `research/`: current PHP and ecosystem research.
- `emw-experiment/`: records that help evaluate EMW's effectiveness.

## Study loop
**Understand → Predict → Experiment → Explain → Implement → Debug → Transfer → Review.**

Do not move to a module merely because its notes were read. Move when its mastery gate is supported by evidence.
