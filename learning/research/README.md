# PHP Research and References

Prefer primary sources:
- PHP Manual: https://www.php.net/manual/en/
- PHP Supported Versions: https://www.php.net/supported-versions.php
- PHP Releases: https://www.php.net/releases.php
- PHP RFCs: https://wiki.php.net/rfc
- Composer documentation: https://getcomposer.org/doc/
- PHP-FIG standards: https://www.php-fig.org/psr/

For fast-changing tooling and libraries, record:
- Source URL and access date.
- Release/version discussed.
- Why it matters to the current project.
- Key facts, trade-offs, and caveats.
- What still requires local verification.

Do not turn an RFC proposal, release candidate, blog post, or AI answer into a stable language guarantee.
