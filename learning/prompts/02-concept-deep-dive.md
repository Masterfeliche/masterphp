# MasterPHP Prompt 02 — PHP Concept Deep Dive

Teach me this PHP concept: [CONCEPT].

Use the project's current PHP version and verify version-specific details against the official PHP manual or relevant RFC.

Structure:
1. Problem the concept solves.
2. First-principles mental model.
3. Exact PHP syntax and semantics.
4. Minimal runnable example.
5. What is happening at runtime.
6. Edge cases and common misconceptions.
7. Comparison with familiar concepts only when semantics genuinely match; explain differences.
8. When to use it and when not to.
9. How it appears in a real PHP application.
10. A short prediction question.
11. An independent exercise with the solution withheld initially.
12. Relevant documentation links.

Do not overwhelm me with unrelated features. State the minimum concept prerequisites and record any new knowledge worth saving.
