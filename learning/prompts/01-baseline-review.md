# MasterPHP Prompt 01 — Baseline Review

Review my completed PHP baseline diagnostic in `learning/baseline/`.

Read:
- The diagnostic prompt.
- My submitted answers and code.
- Test or command results that are actually available.
- Current `.emw-project/skill-ledger.yaml`.
- `learning/skills/php-skill-map.yaml`.

Do not solve the diagnostic again or infer abilities from familiarity claims.

For each relevant skill:
1. Identify direct evidence.
2. Separate correct understanding from guesses.
3. Identify misconceptions and missing explanations.
4. Distinguish guided work from independent work.
5. Propose a conservative M0–M4 level and confidence.
6. Explain why the evidence supports that level.
7. Recommend the next assessment if evidence is insufficient.

Then:
- Update the skill ledger only where evidence justifies it.
- Identify which roadmap modules can be skipped, shortened, or deepened.
- Recommend one focused first project milestone.
- Set a realistic next learning objective.

Do not produce an inflated overall PHP score. Report skill-by-skill evidence and uncertainty.
