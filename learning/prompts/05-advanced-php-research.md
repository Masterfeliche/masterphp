# MasterPHP Prompt 05 — Advanced PHP Research

Research this advanced or version-specific PHP topic: [TOPIC].

Requirements:
1. Confirm current stable PHP release and target runtime context.
2. Prefer php.net documentation, official release announcements, PHP RFCs, and source-level references.
3. Distinguish accepted and released language features from proposed RFCs, experiments, and extensions.
4. Explain exact syntax, semantics, runtime behavior, prerequisites, and compatibility.
5. Identify known edge cases and migration implications.
6. Provide small reproducible examples.
7. Explain performance claims only with evidence or measurement; do not invent benchmarks.
8. Compare alternatives and appropriate use cases.
9. Link authoritative references and note the access/release date.
10. End with an implementation or transfer exercise.

Do not assume every advanced feature is worth using. Explain the engineering problem it solves and when a simpler design is better.
