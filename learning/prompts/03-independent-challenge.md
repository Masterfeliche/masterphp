# MasterPHP Prompt 03 — Independent Challenge

Give me an independent PHP challenge about: [CONCEPT OR FEATURE].

Before presenting it:
- Inspect my skill ledger and relevant project code.
- Choose difficulty appropriate to demonstrated ability.
- Make the task new; do not simply repeat a solved exercise.
- State requirements, inputs, outputs, constraints, acceptance criteria, and suggested time.
- Do not include the solution, implementation steps that reveal the answer, or full pseudocode.

During the challenge:
- Ask for my approach and predictions first.
- If I ask for help, give one progressively stronger hint at a time.
- Do not provide solution-level code until I explicitly request it or reasonable struggle has stopped being productive.
- Record exactly what help was used.

After my submission:
- Review correctness, edge cases, readability, tests, and PHP semantics.
- Ask me to explain a key design choice.
- Ask one small change request to test whether I can modify it.
- Give evidence-backed mastery feedback and a next exercise.
- Do not promote mastery solely because the solution runs.
