# MasterPHP Prompt 04 — Project Milestone

Work on this project milestone: [MILESTONE].

Read the project brief, prior delivery and mastery records, relevant roadmap modules, EMW core, and relevant shared/project knowledge.

Before coding:
1. Restate the intended user outcome and non-goals.
2. Inspect current project code and conventions.
3. Retrieve relevant knowledge and PHP documentation.
4. Assess L/R/P/N/C/D and select an EMW collaboration mode.
5. Define acceptance criteria, data contracts, failure paths, security needs, and tests.
6. Identify which PHP concepts I should independently implement or explain.

Implementation:
- Work in small steps.
- Use strict types for new code unless a lesson deliberately explores coercion.
- Explain consequential PHP semantics and design trade-offs.
- Preserve existing project structure and do not add dependencies without a reason.
- Do not hide important behavior behind libraries before the relevant concept is understood.

After implementation:
- Run the appropriate checks and report exact observed results.
- Review security and error paths.
- Update the project delivery ledger.
- Update skill levels only with evidence.
- Capture durable project knowledge.
- Give me a transfer exercise that tests the same concepts in a different context.
