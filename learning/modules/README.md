# PHP Learning Modules

Modules follow the competency roadmap. Complete the baseline first, then work on the next meaningful gap rather than following an arbitrary beginner course.

Each module should eventually contain:
- Learning outcomes.
- Prerequisites.
- Minimum concepts for the target task.
- Short experiments.
- An independent exercise.
- A practical project application.
- Verification and a mastery gate.
- A delayed retrieval or transfer task.

Use `01-language-foundations/` after the baseline identifies the appropriate starting level.
