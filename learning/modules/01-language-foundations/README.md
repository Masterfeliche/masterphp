# Module 01 — PHP Language Foundations

**Status:** planned; sequence may be shortened or deepened after baseline assessment.

## Outcomes
- Explain how PHP executes in CLI and web contexts.
- Use variables, constants, scalar/compound types, operators, and control flow deliberately.
- Predict PHP comparison, coercion, truthiness, and null behavior.
- Write small functions with useful parameter and return types.
- Read warnings, errors, and stack traces.

## Core concepts
1. PHP runtime, CLI, and source files.
2. Variables, constants, scalar types, arrays, null, and resources.
3. Type declarations, strict typing, coercion, unions, nullable types.
4. Operators, comparisons, truthiness, null coalescing, nullsafe operator.
5. Conditions, loops, match, and expressions.
6. Functions, scope, defaults, named arguments, variadics.
7. Error reporting and exceptions.

## Learning sequence
For each concept:
1. State what you think will happen.
2. Write the smallest possible script.
3. Run it with the target PHP version.
4. Compare observation with prediction.
5. Explain the result without reading the code.
6. Create a variation that would break your first assumption.

## Exercises
- Complete the baseline transaction-summary exercise.
- Write typed functions for filtering, grouping, and summarizing records.
- Debug a reference-related loop bug.
- Create tests for edge cases and invalid inputs.

## Mastery gate
Independently implement and explain a small typed program that transforms nested data, handles malformed input deliberately, and includes checks for boundary cases. Then solve a related problem with a changed requirement without solution-level AI assistance.

Record the attempt, assistance level, test results, and evidence in the mastery ledger.
