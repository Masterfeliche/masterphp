# Independent PHP Exercises

Exercises are designed to produce evidence of capability.

## Rules
- Attempt before reading hints or requesting generated solutions.
- Record the assistance level A0–A4.
- Keep an original submission and any later corrected version separate.
- Include tests or explicit checks.
- Explain important decisions and edge cases.
- Revisit a similar but unfamiliar exercise after a delay.
