# PHP Labs

Labs isolate one PHP behavior at a time. Each lab should be small, executable, and accompanied by a prediction and explanation.

Suggested lab naming:
- `lab-001-runtime-and-cli/`
- `lab-002-types-and-coercion/`
- `lab-003-arrays-and-references/`
- `lab-004-functions-and-closures/`
- `lab-005-oop-and-composition/`

For each lab:
1. Write the question and prediction.
2. Create a minimal PHP script.
3. Run it with the recorded PHP version.
4. Capture output and explain it.
5. Change one variable and predict the new behavior.
6. Record what was learned and what remains uncertain.

Do not store secrets or real customer data in lab files.
