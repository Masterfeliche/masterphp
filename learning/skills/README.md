# PHP Skill Map

The machine-readable map is `php-skill-map.yaml`. It describes the skills MasterPHP intends to practice.

Rules:
- Keep concepts granular enough to assess.
- Link evidence from the project mastery ledger.
- Use prerequisites to plan the next learning step.
- Do not mark a technology mastered because it appears in a project.
- Separate language, runtime, standard library, ecosystem tooling, and framework skills.
